# VirtualScienceLab (VSL)

**Experimental Android application for virtual science lab simulations.**

---

## Overview

VirtualScienceLab (VSL) is an Android application that provides interactive virtual science laboratory experiences. Users can browse and download available chapters directly within the app.

> **Note:** This is an experimental build and may contain bugs or unexpected behavior.

---

## Compatibility

- Android smartphones (Xiaomi, Samsung, and other manufacturers)

---

## Installation

1. Download the APK file from the [Releases](../../releases) section.
2. Tap the file to begin installation. You may need to enable **"Install from unknown sources"** for your file manager or browser.
3. Google Play Protect may prompt you to scan the file. You may either proceed with the scan or continue the installation at your discretion.
4. Once installed, you can browse and download the available chapters from within the application.
